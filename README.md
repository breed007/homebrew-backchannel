# Homebrew tap for Backchannel

```sh
brew install --cask breed007/backchannel/backchannel
```

Backchannel for Mac is Signal Desktop with Backchannel's chat page built in.
Apple Silicon, macOS 14 or later. Releases:
[breed007/Signal-Desktop](https://github.com/breed007/Signal-Desktop/releases).
Source and build notes: `contrib/backchannel/mac/` in
[mikesimone/Signal-Desktop](https://github.com/mikesimone/Signal-Desktop).

Each build stops working 90 days after it's made, like every Signal Desktop
build, so run `brew upgrade --cask backchannel` at least every couple of
months.

`Casks/backchannel.rb` is generated by `contrib/backchannel/mac/release.sh`
for each release; don't edit it by hand.

Backchannel is based on Signal Desktop. It is not made, endorsed or
supported by Signal Messenger.
